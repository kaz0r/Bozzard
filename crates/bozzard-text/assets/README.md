# Bundled Roboto

Roboto from https://github.com/google/fonts/tree/1c627bfa375fc51cf86fabeca4f6e08a95f0aa5c/ofl/roboto

Unmodified `Roboto[wdth,wght].ttf`, renamed `Roboto.ttf`. SIL Open Font License
in `Roboto-OFL.txt`. The default instance is used for Bozzard's Sans text and UI
widgets. It is embedded in the application; players need no system font installation.

The same file is used for width/weight variation and fallback regression tests.
