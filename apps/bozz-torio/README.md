# Bozz-torio

Bozz-torio is a standalone, completely 2D factory game in the Bozzard workspace. Its factory floor is the editable Bozzard scene [`scene/bozz-torio.json`](scene/bozz-torio.json), named **Bozz-torio — Factory Floor**. Its 16 original pixel-art sprites are generated by `tools/generate_sprites.py` and stored in [`assets/sprites.png`](assets/sprites.png). The grid simulation runs at a fixed five ticks per second, independently of rendering.

![Bozz-torio factory with a working starter conveyor line](docs/factory.png)

The [main menu](docs/menu.png) has a matching original visual style.

The supplied scene starts with two miners, two furnaces, two assemblers, 24 conveyors, two splitters, a small item stash, and four credits. Place a miner on an iron deposit, a furnace immediately to its right, and a conveyor line from the furnace to the delivery hub. Eight iron ingots complete the first order. Later orders use gears and circuits. Orders pay credits and award more conveyors; the supply shop sells additional buildings. Deposits never deplete.

## Edit the game scene

From the repository root, open the factory in the Bozzard editor:

```sh
cargo run -p bozzard-editor-app -- --scene apps/bozz-torio/scene/bozz-torio.json
```

Use the **2D** viewport to move ore deposits and the delivery hub, paint the floor tilemap, or duplicate one of the machine templates below the floor and move it onto a grid cell. A miner must sit on an ore deposit. Rotate a placed machine in 90-degree steps to set its output direction. The scene blackboard holds the starter inventory, credits, and first-order amount and reward. Save the scene, open Bozz-torio, and choose **NEW FROM EDITOR SCENE** to play the edited layout. An existing factory save is separate from the scene; **CONTINUE FACTORY** resumes that save. The editor's **Play** button previews the scene layout; Bozz-torio's native window runs its factory simulation and HUD.

The source game is in [`src/`](src/). For a different scene file, start the game with `--scene PATH` and choose **NEW FROM EDITOR SCENE**. The game loads the sprite atlas named by that scene's `assets.sprites.path` entry.

## Run

```sh
cargo run -p bozz-torio -- --offline
cargo run -p bozz-torio -- --steam-app-id 480
```

`--offline` skips Steam initialization. Without it, the game connects to Steam when the client is available and runs offline when it is not. App ID selection is, in order: `--steam-app-id`, `SteamAppId`, a `steam_appid.txt` next to the executable, then the test ID `480`. The latter is only for local development. `--play` opens the factory immediately. `--screenshot PATH` captures the current menu or factory screen and exits.

Controls: `1`–`5` select a machine, `I` inspects, `R` rotates the placement direction, left click places or loads an item, drag lays several conveyors, right click recovers a building, `Space` pauses, `F1` opens the field manual, and `Esc` returns to the menu. Select an item in Inventory and click a compatible building to hand-load it. Inspect an assembler to swap between gear and circuit recipes, or recover a finished output. The game autosaves every ten seconds and on exit to `$XDG_DATA_HOME/bozz-torio/factory.json`, or `~/.local/share/bozz-torio/factory.json` when `XDG_DATA_HOME` is unset.

## Steam depot

Build and stage a depot for your assigned Steamworks App ID:

```sh
python3 apps/bozz-torio/tools/package.py --app-id YOUR_APP_ID --out dist/bozz-torio
```

The package contains the executable, its adjacent Steam API redistributable, `steam_appid.txt`, the editable scene, and its sprite atlas. Keep the scene and assets beside the executable in their packaged directories; the game loads them at startup. The Steam client overlay and rich presence are integrated. The game sends achievements after the stats callback succeeds; configure these API names in the same Steamworks app before testing a release: `BOZZ_FIRST_INGOT`, `BOZZ_FIRST_DELIVERY`, `BOZZ_FACTORY_BUILDER`, and `BOZZ_CIRCUIT_AGE`. Set the Steam launch option to the packaged executable, upload the depot, and test from an account licensed for that app. The app stays playable without a Steam client.

For development without a network, add `--offline` to the package command if the Cargo cache is already populated. The build script in `tools/steam_build.rs` locates the SDK matching the locked `steamworks-sys` dependency; set `STEAM_SDK_LOCATION` when using a separate Steamworks SDK installation.
